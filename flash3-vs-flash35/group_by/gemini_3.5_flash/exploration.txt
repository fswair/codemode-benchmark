--- Snippet 1 [normal]: Happy path grouping list of dicts by existing string keys ---
Code: group_by([{"category": "A", "val": 1}, {"category": "B", "val": 2}, {"category": "A", "val": 3}], "category")
Output: {'A': [{'category': 'A', 'val': 1}, {'category': 'A', 'val': 3}], 'B': [{'category': 'B', 'val': 2}]}

--- Snippet 2 [normal]: Handling missing keys which should group under None ---
Code: group_by([{"id": 1, "type": "X"}, {"id": 2}, {"id": 3, "type": "Y"}], "type")
Output: {'X': [{'id': 1, 'type': 'X'}], None: [{'id': 2}], 'Y': [{'id': 3, 'type': 'Y'}]}

--- Snippet 3 [normal]: Empty list input returns empty dictionary ---
Code: group_by([], "any_key")
Output: {}

--- Snippet 4 [normal]: All items missing the key results in all elements grouped under None ---
Code: group_by([{"a": 1}, {"b": 2}], "c")
Output: {None: [{'a': 1}, {'b': 2}]}

--- Snippet 5 [normal]: Falsy keys are grouped separately from each other and from None ---
Code: group_by([{"val": 0}, {"val": False}, {"val": ""}, {}], "val")
Output: {0: [{'val': False}], '': [{'val': ''}], None: [{}]}

--- Snippet 6 [normal]: Explicit None value vs missing key both map to None group ---
Code: group_by([{"x": None}, {}], "x")
Output: {None: [{'x': None}, {}]}

--- Snippet 7 [normal]: Single item list grouping ---
Code: group_by([{"name": "Alice"}], "name")
Output: {'Alice': [{'name': 'Alice'}]}

--- Snippet 8 [normal]: All items sharing the same group key ---
Code: group_by([{"status": "active"}, {"status": "active"}, {"status": "active"}], "status")

--- Snippet 9 [normal]: Identical dictionaries in input list ---
